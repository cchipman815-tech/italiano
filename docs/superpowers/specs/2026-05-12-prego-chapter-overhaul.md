# Prego Chapter Overhaul — Design Spec

**Date:** 2026-05-12
**Status:** Approved

---

## Overview

A comprehensive overhaul of the Italiano app's content structure and study experience. The app remains a study *tool* (not the main study source) — Prego! An Invitation to Italian (8th ed.) is the source of truth for vocabulary, grammar, and example quality. The overhaul has three pillars:

1. **Content reset** — retire all existing cards/sets; rebuild from Prego chapter vocabulary lists
2. **Richer cards** — add article, word type, adjective forms, tense, chapter tag; improve card display
3. **Sentence Practice mode** — new study mode mixing fill-in-the-blank, dialogue comprehension, and translation challenges; all content generated by Claude at Prego beginner level

---

## Part 1: Data Model Changes

### Cards table — new columns

| Column | Type | Notes |
|---|---|---|
| `chapter` | integer, nullable | Prego chapter number (1–18). Null = untagged. Used for future chapter filtering. |
| `article` | text, nullable | Definite article for nouns: `il`, `la`, `lo`, `l'`, `i`, `le`, `gli`. Stored separately from `italian` field. |
| `word_type` | text, nullable | `noun`, `verb`, `adjective`, `phrase`, `expression`. Drives which back-of-card layout renders. |
| `adjective_forms` | jsonb, nullable | Adjective cards only. Shape: `{ ms: "alto", mp: "alti", fs: "alta", fp: "alte" }` |
| `tense` | text, nullable | Verb cards only. `present`, `past`, `future`. DB default `'present'`. Displayed as a pill on the card front. |

No existing columns are changed or removed.

### New table: `sentences`

Stores Claude-generated sentences linked to cards, used by the Sentence Practice mode.

```sql
CREATE TABLE sentences (
  id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  card_id    uuid REFERENCES cards(id) ON DELETE CASCADE,   -- nullable for dialogue type
  set_id     uuid REFERENCES sets(id) ON DELETE CASCADE,    -- used by dialogue type (whole-set scope)
  italian    text NOT NULL,
  english    text NOT NULL,
  type       text NOT NULL CHECK (type IN ('example', 'fill_blank', 'dialogue', 'translation')),
  chapter    integer,
  created_at timestamptz DEFAULT now()
);
```

`card_id` is nullable — fill_blank, translation, and example sentences link to a specific card; dialogue sentences belong to a set and link via `set_id` instead. At least one of `card_id` or `set_id` must be non-null (enforced by application logic).

### Migration files

- `supabase/migrations/007_chapter_overhaul.sql` — adds all new card columns + creates sentences table

## Part 2: Content Reset & Chapter-Based Sets

### Existing data

All existing sets and cards are **deleted** via a reset script (`scripts/reset-content.ts`) that truncates the `sets` and `cards` tables. Progress rows cascade-delete automatically (the `progress` table has `card_id` FK with `ON DELETE CASCADE`). The `progress` table structure itself is unchanged. This is the correct trade-off: accurate, chapter-organized content is more valuable than accumulated history on inaccurate content.

### New set structure

Sets are reorganized by Prego chapter. Each set contains all card types for that chapter (nouns, verbs, adjectives) mixed together — mirroring how the content is taught in class.

| Set title | Chapter | Key content |
|---|---|---|
| Chapter 1 — Una città italiana | 1 | Places, transport, directions; `avere`; indefinite articles; noun gender/number |
| Chapter 2 — Come siamo | 2 | Adjectives, colors, nationalities; `essere`; definite articles; `bello` |
| Chapter 3 — Studiare in Italia | 3 | Family, university, subjects; `-are` verbs; possessives; `questo`/`quello` |
| Chapter 4 — Sport e passatempi | 4 | Sports, hobbies, weather; `-ere`/`-ire` verbs; direct object pronouns; telling time |
| Chapter 5 — Caffè e cappuccino | 5 | Bar/café vocabulary; articulated prepositions; `passato prossimo` with avere |
| *(further chapters added on demand)* | | |

### Seeding strategy

A new script `scripts/seed-chapters.ts` reads the *Parole da ricordare* vocabulary lists extracted from the Prego PDF and seeds each chapter's cards with:
- Correct `italian` value (noun without article, verb as infinitive, adjective as masculine singular)
- Correct `article` (for nouns)
- Correct `english`
- `gender` (for nouns where detectable)
- `plural` (for nouns)
- `word_type`
- `chapter`
- `adjective_forms` (for adjectives — all 4 forms)
- `tense: 'present'` (for verb cards)
- `conjugations.present` (for verb cards that have conjugation tables)

Example sentences (`example` field) are generated via Claude after seeding via an updated `scripts/backfill-examples.ts`.

### Future chapter additions

Adding Chapter 4+ content is a single script run:
```bash
npx tsx scripts/seed-chapters.ts --chapter 4
```

Chapter filtering in study modes (study only Ch. 3–5, exclude Ch. 1–2) is **not** built in this release but is enabled by the `chapter` column being present from day one.

## Part 3: Richer Card Display

### Study direction toggle

Shown on the set detail page as a toggle above the Flashcard and Sentence Practice mode buttons. Chosen once before the session starts — not changeable mid-session. Two options:
- 🇮🇹 **Italian → English** (default): Italian word/phrase on front, English translation on back
- 🇺🇸 **English → Italian**: English on front, Italian on back

Applies to Flashcard mode. Sentence Practice has its own per-format direction (see Part 4).

### Card front

All card types show:
- Word type pill (e.g. `Noun · Ch. 1`)
- Tense pill for verbs (e.g. `Present`) in purple
- The Italian word (or English word if direction is EN→IT)
- Speaker (🔊) button next to the word — calls existing `/api/tts`
- **Only the blue "Tap to flip" bar at the bottom flips the card** — tapping the card body or speaker icon does not flip

### Card back — by word type

**Noun:**
- English translation + speaker button
- Article + singular form, plural form, gender badge in a metadata row (e.g. `M  il libro · pl. i libri`)
- Claude-generated example sentence with Italian + English + speaker button on the Italian

**Verb:**
- English translation + speaker button
- Tense label ("Conjugation — Present")
- 3-column conjugation grid, always with pronoun labels: `io`, `tu`, `lui/lei` on the left, `noi`, `voi`, `loro` on the right
- Claude-generated example sentence

**Adjective:**
- English translation + speaker button
- 2×2 forms grid: M. sing. / F. sing. / M. plural / F. plural
- Claude-generated example sentence

**All back sides:**
- Answer bar split left/right: **← Don't know** (red, left) and **Got it →** (blue, right)
- No full-card click to answer — only the labeled buttons

## Part 4: Sentence Practice Mode

A new study mode accessible from the set detail page alongside Flashcards, Quiz, Match, Listening, and Review.

### Session structure

10 questions per session, mixing three question formats. Claude generates the full batch when a session starts; the batch is stored in the `sentences` table so it is reused on subsequent sessions unless new cards have been added.

### Format 1 — Fill in the blank

Best suited for verbs, nouns, and adjectives. A sentence is shown with one word blanked out. Four multiple-choice options are shown in a 2×2 grid. After answering, a feedback bar shows whether the answer was correct and briefly explains the grammar (e.g. "Avere — io ho").

English translation of the sentence is always visible below the Italian sentence.

### Format 2 — Dialogue comprehension

A short 2–4 line Prego-style Italian exchange is shown. All English translations are **hidden by default**. A single 👁 **Show translations** button at the top-right of the dialogue reveals/hides all English translations across every line simultaneously — the user can challenge themselves to read the Italian first, then check understanding.

One comprehension question follows the dialogue (always in Italian, answered in English). The question also has a hidden English translation controlled by the same eye button.

Difficulty is beginner-appropriate — vocabulary limited to cards in the current set plus common ch. 1–2 phrases.

### Format 3 — Translation challenge

A sentence is shown in one language; the user picks the correct translation from three options.

Direction is chosen before the session starts (same toggle as flashcards):
- **EN→IT**: English sentence shown, pick the correct Italian translation
- **IT→EN**: Italian sentence shown, pick the correct English translation

After answering, the feedback bar explains the key grammar point (e.g. "alta — feminine singular of alto").

### Claude generation prompt guidance

The `/api/sentences/generate` endpoint instructs Claude to:
- Use only vocabulary from the current set (card `italian` and `english` values are passed as context)
- Keep sentences to 5–10 words
- Match Prego chapter 1–3 grammar complexity (no subjunctive, no conditional, no past tense unless the set contains passato prossimo cards)
- For fill-in-blank: blank a noun, verb conjugation form, or adjective (not articles or prepositions)
- For dialogues: write natural beginner exchanges with 2 speakers, 2–3 lines each
- For translation: include one subtle grammar trap per question (e.g. gender agreement, word order)
- Return structured JSON matching the `sentences` table schema

## Part 5: Claude API Integration

### New shared wrapper: `/api/claude`

A thin internal route that wraps the Anthropic SDK. All Claude-powered features call this route rather than calling the SDK directly. Keeps model selection, system prompt defaults, and error handling in one place.

```
POST /api/claude
Body: { prompt: string, systemPrompt?: string, maxTokens?: number }
Returns: { content: string }
```

### Updated routes

| Route | Change |
|---|---|
| `/api/example` | Replace Google Translate call with Claude via `/api/claude` |
| `/api/plural` | Replace Google Translate call with Claude via `/api/claude` |
| `/api/sentences/generate` | New — generates a 10-question Sentence Practice session batch |
| `/api/cards/[id]` | Accept new fields: `word_type`, `article`, `chapter`, `adjective_forms`, `tense` |

### Environment variable

`ANTHROPIC_API_KEY` — new required env var for Claude API access. Added to `.env.local` and Vercel project settings.

## Part 6: CardEditor Updates

The CardEditor expand/collapse panel gains fields for the new card columns:
- `word_type` selector (noun / verb / adjective / phrase / expression)
- `article` text input (for nouns)
- `chapter` number input
- `tense` selector for verb cards (present / past / future)
- `adjective_forms` 4-field grid for adjective cards (already has conjugation grid pattern to follow)

Generate buttons for `example` and `plural` are updated to call Claude via the updated API routes.
